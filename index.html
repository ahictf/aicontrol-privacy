นโยบายความเป็นส่วนตัว

AI Control เป็นส่วนขยายสำหรับอุปกรณ์ขององค์กร ใช้บังคับนโยบายการใช้งาน AI ขององค์กร OCEAN LIFE Insurance (“องค์กร”) โดยบล็อกบริการ AI ที่ผู้ดูแลระบบกำหนด ตรวจว่าใช้บัญชีองค์กรหรือไม่ ตรวจข้อมูลอ่อนไหวในข้อความที่ส่งไปยังบริการ AI และแจ้งให้องค์กรทราบว่ามีการเข้าถึงบริการ AI ใดบ้าง องค์กรเป็นผู้ควบคุมข้อมูล ผู้พัฒนาส่วนขยายไม่ได้รับข้อมูลใดๆ พนักงานได้รับแจ้งจากองค์กรล่วงหน้าเกี่ยวกับการทำงานนี้

ข้อมูลที่ส่งออกจากเบราว์เซอร์

ชื่อโฮสต์ของเว็บไซต์ (เช่น chatgpt.com)เมื่อผู้ใช้เปิดหน้าเว็บของบริการ AI ที่องค์กรเฝ้าดู หรือเว็บที่ชื่อดูเหมือนบริการ AI ส่งชื่อโฮสต์ พร้อมเวลา ว่าถูกบล็อกหรือไม่ และชื่อบริการ ไม่ส่ง URL เต็ม พารามิเตอร์ หรือชื่อหน้า ส่งไม่เกินหนึ่งครั้งต่อโฮสต์ต่อหนึ่งนาที
ข้อความที่ส่งไปยังบริการ AI (prompt)เฉพาะบนเว็บ AI ที่องค์กรกำหนด (ChatGPT, Claude, Gemini) และเฉพาะกลุ่มผู้ใช้ที่องค์กรเปิดฟีเจอร์นี้ ส่วนขยายอ่านข้อความที่ผู้ใช้ส่งไปยังบริการ AI ลบรหัสผ่าน คีย์ และความลับที่ตรวจพบในเบราว์เซอร์ก่อน ตัดให้ไม่เกิน 100,000 ตัวอักษร แล้วส่งไปยังเซิร์ฟเวอร์ขององค์กร พร้อมเวลา ชื่อบริการ และรหัสการสนทนา (จากรหัสแชตในที่อยู่หน้าเว็บ) เพื่อจัดข้อความเป็นบทสนทนา ไม่อ่านคำตอบของ AI และไม่อ่านไฟล์แนบ
ผลตรวจข้อมูลอ่อนไหวส่วนขยายตรวจในเครื่องว่าข้อความมีข้อมูลอ่อนไหว (เช่น เลขบัตรประชาชน เลขบัตรเครดิต คีย์ลับ หรือคำที่องค์กรกำหนด) ส่งเฉพาะชนิดของข้อมูลที่พบให้โปรแกรม agent ขององค์กร ตามที่องค์กรตั้งค่า (ปิด / รายงาน / บล็อก)
อีเมลของบัญชีบนเว็บ AIเมื่อองค์กรเปิดการตรวจบัญชี ส่วนขยายอ่านอีเมลของบัญชีที่ลงชื่อเข้าใช้บนเว็บ AI และส่งให้ agent ขององค์กรบนเครื่องเพื่อตัดสินว่าเป็นบัญชีองค์กรหรือบัญชีส่วนตัว
อีเมลของผู้ใช้เครื่องเฉพาะเมื่อใช้งานแบบเชื่อมต่อเซิร์ฟเวอร์โดยตรง (ไม่มีโปรแกรม agent ขององค์กรบนเครื่อง) ส่วนขยายส่งอีเมลที่ผู้ดูแลระบบตั้งค่าไว้ หรืออีเมลของบัญชีเบราว์เซอร์ที่ลงชื่อเข้าใช้ (Chrome) เพื่อให้ทราบว่าต้องใช้นโยบายของผู้ใช้คนใด
รหัสอุปกรณ์รหัสสุ่มที่สร้างตอนลงทะเบียนครั้งแรกกับเซิร์ฟเวอร์ขององค์กร และเวอร์ชันของส่วนขยาย เพื่อใช้ยืนยันตัวตนของส่วนขยายกับเซิร์ฟเวอร์

การใช้คุกกี้

ส่วนขยายไม่ส่งคุกกี้ออกจากเครื่อง และไม่นำค่าของคุกกี้ไปใช้ สิทธิ์ cookies ใช้เพียงอย่างเดียวคือ ลบคุกกี้ของเว็บ AI เพื่อออกจากระบบบัญชีส่วนตัว เมื่อองค์กรตั้งโหมดบล็อกบัญชีส่วนตัวและตรวจพบว่าไม่ใช่บัญชีองค์กร

ข้อมูลที่ไม่เก็บ

ส่วนขยายไม่เก็บสิ่งที่ผู้ใช้พิมพ์บนเว็บอื่นนอกเหนือจากเว็บ AI ที่องค์กรกำหนด ไม่เก็บข้อมูลในแบบฟอร์ม รหัสผ่าน ประวัติการท่องเว็บทั่วไป หรือเว็บที่ไม่เกี่ยวกับบริการ AI (เว็บเหล่านั้นถูกตรวจในเครื่องเพื่อเทียบกับรายการ และไม่ถูกส่งออก) content script ทำงานเฉพาะบน chatgpt.com, claude.ai และ gemini.google.com

ข้อมูลที่เก็บในเครื่อง

ส่วนขยายเก็บในพื้นที่เก็บข้อมูลของเบราว์เซอร์บนเครื่องนี้เท่านั้น (ไม่ซิงก์ไปเครื่องอื่น): รายการโดเมนที่องค์กรกำหนด ข้อความหน้าบล็อก สถานะที่แสดงในหน้าต่างเล็กของส่วนขยาย ผลการตรวจบัญชีล่าสุด (เหตุผลและเวลา ไม่มีอีเมล) และข้อมูลลงทะเบียนอุปกรณ์กับเซิร์ฟเวอร์ (ในโหมดเชื่อมต่อโดยตรง)

ผู้รับข้อมูลและการใช้ข้อมูล

ข้อมูลส่งไปยังเซิร์ฟเวอร์ AI Control ขององค์กรเท่านั้น (ผ่านโปรแกรม agent ขององค์กรบนเครื่อง หรือโดยตรงทาง HTTPS) ใช้เพื่อบังคับนโยบาย ป้องกันข้อมูลรั่วไหล และให้ผู้ดูแลระบบตรวจสอบการใช้บริการ AI เท่านั้น ไม่ขาย ไม่แบ่งปันกับบุคคลที่สาม ไม่ใช้โฆษณา ไม่ใช้สร้างโปรไฟล์ ไม่ใช้พิจารณาสินเชื่อ และไม่ใช้เพื่อวัตถุประสงค์อื่น ส่วนขยายไม่มีการวิเคราะห์การใช้งานหรือบริการติดตามของบุคคลที่สาม

ความปลอดภัย

การสื่อสารกับเซิร์ฟเวอร์ใช้ HTTPS (หรือการเชื่อมต่อภายในเครื่องกับ agent) ข้อความ prompt ที่เก็บถูกเข้ารหัสในฐานข้อมูลขององค์กร และเปิดอ่านได้เฉพาะผู้ดูแลระบบและผู้ตรวจสอบ (Admin / Auditor) โดยทุกครั้งที่เปิดอ่านจะถูกบันทึกในบันทึกการตรวจสอบ นโยบายที่ส่งมาถูกลงลายมือชื่อดิจิทัล และ agent ขององค์กร (หรือส่วนขยายเอง ในโหมดเชื่อมต่อโดยตรง) ตรวจสอบก่อนใช้ นโยบายที่ลายมือชื่อไม่ถูกต้องจะถูกปฏิเสธ

ระยะเวลาเก็บรักษาและสิทธิของผู้ใช้

ข้อความ prompt ถูกเก็บ 90 วัน แล้วลบ ข้อมูลอื่นเก็บตามนโยบายขององค์กร หากต้องการสอบถาม ขอเข้าถึง แก้ไข หรือลบข้อมูล หรือใช้สิทธิอื่นตามกฎหมายคุ้มครองข้อมูลส่วนบุคคล กรุณาติดต่อฝ่ายโครงสร้างเทคโนโลยีสารสนเทศขององค์กร saran.kaewnang@gmail.com

Privacy Policy

AI Control is an extension for organization-managed devices. It enforces the AI usage policy of OCEAN LIFE Insurance (the “Organization”): it blocks the AI services the administrator restricts, checks whether a company account is used, checks for sensitive data in text sent to AI services, and tells the Organization which AI services were accessed. The Organization is the data controller. The extension’s developer receives no data. Employees are informed by the Organization in advance.

Data that leaves the browser

Host names of websites (for example chatgpt.com)When the user opens a page of an AI service the Organization watches, or a site whose name looks like an AI service, the extension sends the host name, the time, whether it was blocked and the service name. It never sends the full URL, query or page title, and at most once per host per minute.
Text sent to AI services (prompts)Only on the AI sites the Organization lists (ChatGPT, Claude, Gemini) and only for user groups for which the Organization turned this on. The extension reads the text the user submits to the AI service, blanks passwords, keys and other secrets it detects in the browser first, clips it to 100,000 characters and sends it to the Organization’s server with the time, service name and a conversation id (taken from the chat id in the page address) so messages can be grouped into conversations. It does not read the AI’s replies or attached files.
Sensitive-data findingsThe extension checks on the device whether the text contains sensitive data (for example national ID or card numbers, secret keys, or terms the Organization defined). It sends only the kinds of data found to the Organization’s agent, as the Organization configured (off / report / block).
E-mail of the account signed in on the AI siteWhen the Organization turns the account check on, the extension reads the e-mail of the account signed in on the AI site and sends it to the Organization’s agent on the device to decide whether it is a company or a personal account.
Device user e-mailOnly in direct-connection mode (no organization agent on the device): the e-mail set by the administrator, or the e-mail of the signed-in browser profile (Chrome), so the server knows whose policy applies.
Device identifierA random identifier created when the extension first registers with the Organization’s server, and the extension version, used to authenticate the extension to that server.

Use of cookies

The extension does not send cookies off the device and does not use cookie values. The cookies permission has one use: to delete the AI site’s cookies so a personal account is signed out, when the Organization sets personal accounts to be blocked and a non-company account is detected.

Data that is not collected

The extension does not collect what you type on sites other than the AI sites the Organization lists, form data, passwords, general browsing history, or sites unrelated to AI services (those are compared with the list on the device and never sent). Its content script runs only on chatgpt.com, claude.ai and gemini.google.com.

Data stored on the device

Stored only in the browser’s extension storage on this device (not synced): the domain lists set by the Organization, the block page text, the status shown in the extension popup, the result of the last account check (reason and time, no e-mail) and, in direct-connection mode, the device’s registration with the server.

Recipients and use

Data goes only to the Organization’s own AI Control server (through the Organization’s agent on the device, or directly over HTTPS). It is used only to enforce the policy, prevent data leaks and let administrators review the use of AI services. It is not sold, not shared with third parties, not used for advertising, profiling or credit decisions, and not used for any other purpose. The extension contains no analytics and no third-party trackers.

Security

Communication with the server uses HTTPS (or a local connection to the agent). Stored prompt text is encrypted in the Organization’s database and can be read only by administrators and auditors (Admin / Auditor); every read is recorded in an audit log. Policies are digitally signed and the Organization’s agent (or the extension itself in direct-connection mode) verifies the signature before applying them; a policy with an invalid signature is rejected.

Retention and your rights

Prompt text is kept for 90 days and then deleted. Other data is kept as the Organization’s policy sets.
