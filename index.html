AI Control

ส่วนขยายเบราว์เซอร์ / Browser extension · มีผลตั้งแต่ / Effective 3 October 2026

ภาษาไทยEnglish

นโยบายความเป็นส่วนตัว

AI Control เป็นส่วนขยายสำหรับอุปกรณ์ขององค์กร ใช้บังคับนโยบายการใช้งาน AI ขององค์กร <ชื่อองค์กร> (“องค์กร”) โดยบล็อกบริการ AI ที่ผู้ดูแลระบบกำหนด และแจ้งให้องค์กรทราบว่ามีการเข้าถึงบริการ AI ใดบ้าง องค์กรเป็นผู้ควบคุมข้อมูล ผู้พัฒนาส่วนขยายไม่ได้รับข้อมูลใดๆ

ข้อมูลที่ส่งออกจากเบราว์เซอร์

ชื่อโฮสต์ของเว็บไซต์ (เช่น chatgpt.com)เมื่อผู้ใช้เปิดหน้าเว็บของบริการ AI ที่องค์กรเฝ้าดู หรือเว็บที่ชื่อดูเหมือนบริการ AI ส่งเฉพาะ ชื่อโฮสต์ พร้อมเวลา ว่าถูกบล็อกหรือไม่ และชื่อบริการ ไม่ส่ง URL เต็ม เส้นทาง พารามิเตอร์ ชื่อหน้า หรือเนื้อหาหน้า ส่งไม่เกินหนึ่งครั้งต่อโฮสต์ต่อหนึ่งนาที
อีเมลของบัญชีเฉพาะเมื่อใช้งานแบบเชื่อมต่อเซิร์ฟเวอร์โดยตรง (ไม่มีโปรแกรม agent ขององค์กรบนเครื่อง) ส่วนขยายส่งอีเมลที่ผู้ดูแลระบบตั้งค่าไว้ หรืออีเมลของบัญชีเบราว์เซอร์ที่ลงชื่อเข้าใช้ (Chrome) เพื่อให้ทราบว่าต้องใช้นโยบายของผู้ใช้คนใด
รหัสอุปกรณ์รหัสสุ่มที่สร้างตอนลงทะเบียนครั้งแรกกับเซิร์ฟเวอร์ขององค์กร และเวอร์ชันของส่วนขยาย เพื่อใช้ยืนยันตัวตนของส่วนขยายกับเซิร์ฟเวอร์

ข้อมูลที่ไม่เก็บ

ส่วนขยายไม่อ่านเนื้อหาหน้าเว็บ ไม่มี content script ไม่เก็บสิ่งที่ผู้ใช้พิมพ์ ข้อมูลในแบบฟอร์ม รหัสผ่าน คุกกี้ ประวัติการท่องเว็บทั่วไป หรือเว็บที่ไม่เกี่ยวกับบริการ AI (เว็บเหล่านั้นถูกตรวจในเครื่องเพื่อเทียบกับรายการ และไม่ถูกส่งออก)

ข้อมูลที่เก็บในเครื่อง

ส่วนขยายเก็บในพื้นที่เก็บข้อมูลของเบราว์เซอร์บนเครื่องนี้เท่านั้น (ไม่ซิงก์ไปเครื่องอื่น): รายการโดเมนที่องค์กรกำหนด ข้อความหน้าบล็อก สถานะที่แสดงในหน้าต่างเล็กของส่วนขยาย และข้อมูลลงทะเบียนอุปกรณ์กับเซิร์ฟเวอร์ (ในโหมดเชื่อมต่อโดยตรง)

ผู้รับข้อมูลและการใช้ข้อมูล

ข้อมูลส่งไปยังเซิร์ฟเวอร์ AI Control ขององค์กรเท่านั้น (ผ่านโปรแกรม agent ขององค์กรบนเครื่อง หรือโดยตรงทาง HTTPS) ใช้เพื่อบังคับนโยบายและให้ผู้ดูแลระบบตรวจสอบการเข้าถึงบริการ AI เท่านั้น ไม่ขาย ไม่แบ่งปันกับบุคคลที่สาม ไม่ใช้โฆษณา ไม่ใช้สร้างโปรไฟล์ ไม่ใช้พิจารณาสินเชื่อ และไม่ใช้เพื่อวัตถุประสงค์อื่น ส่วนขยายไม่มีการวิเคราะห์การใช้งานหรือบริการติดตามของบุคคลที่สาม

ความปลอดภัย

การสื่อสารกับเซิร์ฟเวอร์ใช้ HTTPS (หรือการเชื่อมต่อภายในเครื่องกับ agent) นโยบายที่ส่งมาถูกลงลายมือชื่อดิจิทัล และ agent ขององค์กร (หรือส่วนขยายเอง ในโหมดเชื่อมต่อโดยตรง) ตรวจสอบก่อนใช้ นโยบายที่ลายมือชื่อไม่ถูกต้องจะถูกปฏิเสธ

ระยะเวลาเก็บรักษาและสิทธิของผู้ใช้

ระยะเวลาเก็บรักษาข้อมูลบนเซิร์ฟเวอร์เป็นไปตามนโยบายขององค์กร หากต้องการสอบถาม ขอเข้าถึง แก้ไข หรือลบข้อมูล หรือใช้สิทธิอื่นตามกฎหมายคุ้มครองข้อมูลส่วนบุคคล กรุณาติดต่อฝ่ายโครงสร้างเทคโนโลยีสารสนเทศขององค์กร <อีเมลติดต่อ>

การเปลี่ยนแปลงนโยบาย

หากมีการเปลี่ยนแปลงข้อมูลที่ส่งออก จะปรับหน้านี้และวันที่มีผลบังคับใช้ก่อนปล่อยเวอร์ชันที่เปลี่ยน

Privacy Policy

AI Control is an extension for organization-managed devices. It enforces the AI usage policy of <Organization name> (the “Organization”): it blocks the AI services the administrator restricts and tells the Organization which AI services were accessed. The Organization is the data controller. The extension’s developer receives no data.

Data that leaves the browser

Host names of websites (for example chatgpt.com)When the user opens a page of an AI service the Organization watches, or a site whose name looks like an AI service, the extension sends only the host name, the time, whether it was blocked and the service name. It never sends the full URL, path, query, page title or page content, and at most once per host per minute.
Account e-mailOnly in direct-connection mode (no organization agent on the device): the e-mail set by the administrator, or the e-mail of the signed-in browser profile (Chrome), so the server knows whose policy applies.
Device identifierA random identifier created when the extension first registers with the Organization’s server, and the extension version, used to authenticate the extension to that server.

Data that is not collected

The extension does not read page content, has no content scripts, and does not collect what you type, form data, passwords, cookies, general browsing history, or sites unrelated to AI services (those are compared with the list on the device and never sent).

Data stored on the device

Stored only in the browser’s extension storage on this device (not synced): the domain lists set by the Organization, the block page text, the status shown in the extension popup and, in direct-connection mode, the device’s registration with the server.

Recipients and use

Data goes only to the Organization’s own AI Control server (through the Organization’s agent on the device, or directly over HTTPS). It is used only to enforce the policy and to let administrators review access to AI services. It is not sold, not shared with third parties, not used for advertising, profiling or credit decisions, and not used for any other purpose. The extension contains no analytics and no third-party trackers.

Security

Communication with the server uses HTTPS (or a local connection to the agent). Policies are digitally signed and the Organization’s agent (or the extension itself in direct-connection mode) verifies the signature before applying them; a policy with an invalid signature is rejected.

Retention and your rights

How long data is kept on the server is set by the Organization’s own policy. To ask questions, or to request access, correction or deletion of data or exercise other rights under data-protection law, contact the Organization’s IT Infrastructure Department <contact e-mail>.

Changes

If the data that leaves the browser changes, this page and its effective date are updated before the changed version is released.
